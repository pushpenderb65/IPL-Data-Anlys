# 🏏 IPL Match Exploratory Data Analysis (EDA)

A comprehensive data analysis project exploring historical 
Indian Premier League (IPL) match datasets to uncover performance
trends, team statistics, and player insights.

## 📈 Highlights
* Data cleaning and normalization of complex dataset names.
* Deep-dive statistical analysis using Python.
* Rich visualizations mapping match performance and historical trends.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Matplotlib, Seaborn, Jupyter Notebook
